# 手柄操作

支持 UE 标准 Gamepad 输入。Windows 优先使用系统可识别的 XInput 手柄；
PlayStation 标注表示按键位置，不能保证所有原生驱动直接兼容。

| 操作 | Xbox | PlayStation 对应位置 |
|---|---|---|
| 移动 | 左摇杆 | 左摇杆 |
| 视角 | 右摇杆 | 右摇杆 |
| 普攻 | 按住 X | 按住 □ |
| 闪避 | A | × |
| 技能 | Y | △ |
| 锁定切换 | 按下右摇杆 | R3 |
| 跑步 | 按住 LB | 按住 L1 |

攻击按住自动在续段窗口接下一段，五段结束后继续下一轮。
松开后不追加自动攻击，当前段正常结束。鼠标点击缓存独立保留。
闪避和技能沿用原有取消规则。摇杆有死区，视角转速按秒计算。

编译已通过。实体手柄的识别、死区手感和按键布局仍需实机验证。
