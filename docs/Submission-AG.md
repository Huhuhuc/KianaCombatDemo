# Kiana Combat Demo — 试题一设计说明

作者：胡宸凡　姓名拼音：huchenfan

版本日期：2026-10-04。应聘方向：动作预研。

我围绕“观察前摇、闪避规避、利用恢复期进攻”的循环制作了这个第三人称战斗原型，希望通过单敌人与多敌人场景，展示动作衔接、攻击反馈和空间选择之间的关系。本文说明当前版本的设计、操作与实现边界。

## A 操作说明书
UE 5.8.1，第三人称地面动作战斗。进入 L_CombatArena 后先选择难度，再开始。

| 操作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 移动、视角 | WASD、鼠标移动 | 左、右摇杆 |
| 跑步 | 按住 Shift | 按住 LB |
| 普攻 | 连续点击左键 | 按住 X，松开停止追加 |
| 闪避 | 空格，配合移动方向 | A，配合左摇杆 |
| 技能 | E | Y |
| 锁定切换 | Tab | R3 |
| 难度 | 1/左方向键：简单；2/右方向键：困难 | 十字键左右 |
| 开始 | P 或 Enter | Start |

右键不参与普通连招。死亡或胜利后，可通过重试按钮重新进入关卡；跌出场地达到死亡阈值后判定失败。手柄按 Xbox 键位标注，目前已配置输入，但我尚未完成实体手柄验证。

我采用单轮计数缓存：每次左键按下记录一次攻击，最多排入本轮剩余段数。五次连续点击可依次执行 Attack1→Attack2→Attack3→Attack4→Attack5，第五段后不自动开始下一轮。快速完成五次输入后，角色会继续执行已记录的攻击；闪避、技能或受击会取消尚未执行的队列。

## B 角色与怪物技能设定

我的设计目标是让玩家通过动作选择获得进攻机会，同时让敌人的前摇、受击与恢复形成可辨识的攻防节奏。

玩家 Kiana：通过走跑调整距离，五段普攻施压，方向闪避规避攻击，范围技能制造硬直机会。普攻逐段提高伤害，每段对同一目标最多结算一次。闪避有短暂无敌窗口，方向位移受碰撞约束；技能有冷却，不无限连续释放。受击打断、死亡终止战斗。

敌人 Strike Jaeger：感知玩家后接近，在攻击距离内预警，轮换六种攻击并进入恢复。近距离可绕行、退让；轻重受击按前后方向选择动作，重击后进入眩晕开始、循环、结束与恢复，重复受击不会无限重置眩晕。可执行后、左、右闪避；生命归零进入死亡终态。追击为直接移动，尚无复杂障碍寻路。

我设置了简单与困难两种模式，分别生成 1 个和 4 个敌人，并扩大困难模式的出生间距。我希望难度差异主要体现为空间压力与目标管理，而不只是生命值的提升。当前尚未实现完善的围攻调度。

最小反馈：扣血事件触发命中粒子；技能有效帧触发径向爆发；闪避启动触发方向粒子。命中位置来自碰撞体表面近似点，不是精确武器接触点。特效不改变伤害、连击缓存或无敌帧。

## C 背景与攻略
战斗训练场：玩家挑战 Strike Jaeger，简单模式练习单体攻防，困难模式练习距离与目标管理。观察敌人前摇，闪避后利用恢复期攻击；避免在多名敌人之间长时间站定连击，利用技能创造脱离或进攻机会。此背景仅为训练场叙事，不代表角色官方设定。

## G 插件、AI 与辅助开发说明
本项目由我主导制作，开发过程中使用 AI 辅助代码实现、问题排查、自动化测试和改进建议。

项目启用记录包含 PythonScriptPlugin、ModelContextProtocol、AllToolsets、ModelingToolsEditorMode；运行代码使用 Enhanced Input、UMG、Niagara 等 UE 模块。通过本地 ue_mcp_bridge.py 使用 UE 官方 Python 远程执行协议连接编辑器。
