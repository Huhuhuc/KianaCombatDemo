# Kiana Combat Demo

基于 Unreal Engine 5.8.1 的第三人称动作战斗原型，围绕「观察前摇 → 闪避规避 → 利用恢复期进攻」设计攻防循环。个人作品集项目，负责玩法规则与设计取舍，使用 Codex 辅助代码实现、资产绑定、测试与文档整理。

## 公开版本范围

本仓库提供 C++ 源码、UE 配置、Python 工具、设计说明与历史测试证据。**不包含角色模型、动画、贴图、UI 图像及完整 Content 资源，因此克隆后不能直接运行完整演示。** 核心美术来自笔试附件，部分资源来源仍待核对；公开仓库不分发这些资产，也不将其声明为原创。未附加覆盖第三方资产的开源许可。

## 设计与实现

- 五段普攻：单轮计数输入缓存，上限为本轮剩余段数；闪避、技能或受击清除旧队列。
- 方向闪避与短暂无敌窗口、带冷却的范围技能、受击打断与死亡终态。
- 敌人追击、绕行、六种攻击、前后轻重受击、眩晕恢复、三方向闪避；避免重击无限重置眩晕。
- 简单 / 困难模式分别生成 1 / 4 个敌人，以数量及出生间距形成空间压力差异。
- 锁定、多目标血条、伤害数字、命中 / 技能 / 闪避 Niagara 反馈、胜负重试与坠落失败。

## 验证记录与边界

保存报告中，敌人行为检查 12/12 通过；0.01 / 0.35 / 0.55 秒输入间隔三组连招检查均按序执行五段并回到待机；单击及闪避、技能、受击取消四项通过。它们是历史 PIE 自动化记录，使用 debug 调用，不代表实体鼠标、手柄或完整产品体验已经验收。旧文档中的单槽缓存失败记录属于迭代历史，以最新计数缓存报告为准。

尚未完成：逐动作接触帧校准、完整 AnimBP / BlendSpace / Montage 数据化、多敌人调度与复杂障碍寻路、实体手柄验收及 Windows 独立打包。

## 本地恢复完整项目

需要 Unreal Engine 5.8 系列、C++ 构建工具和合法获取的原始资产。恢复 `Content/CombatDemo` 下的地图、蓝图、角色及动画引用后，再生成工程并构建 Editor target。`.uproject` 保留原项目的 ModelContextProtocol / AllToolsets 插件声明；未安装者需要自行安装或审查依赖后调整声明。脚本包含开发机绝对路径，使用前需改为本地项目路径。资源导入脚本不是完整的一键重建流程。

详细设计见 [设计说明](docs/设计说明.md)，验收限制见 [验收台账](docs/Acceptance-2026-10-04.md)。
